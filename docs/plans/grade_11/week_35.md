## Day 1 — Monday (school day 171, ~440 min)

## Objectives, materials & assessment

### English 11 – American Literature: Year-end synthesis and portfolio
- Objective: Connect texts across periods
- Objective: Curate and reflect on a writing portfolio
- Vocabulary: portfolio, reflection, thematic thread
- Materials: all year's texts, digital portfolio (Google Sites or similar)
- Assessment: Portfolio and presentation rubric.

### Algebra II: Modeling capstone
- Objective: Select and justify a function model for real data
- Vocabulary: model selection, residual, regression
- Materials: public data set (CA population, COVID, temperature), Desmos
- Assessment: Capstone presentation rubric.

### Physics of the Universe: Engineering capstone: build a generator or wind turbine
- Objective: Design, build, test, and refine an energy-conversion device
- Objective: Use a simulation to model a solution
- Vocabulary: prototype, efficiency, blade pitch, iteration, load
- Materials: small DC motor (used as generator), cardboard or plastic bottle blades, LED, box fan, multimeter if available
- Assessment: Capstone design rubric.

### U.S. History & Geography: Continuity and Change in the Twentieth Century: History research project: build and present
- Objective: Build an evidence-based argument
- Objective: Present historical research
- Vocabulary: exhibit, documentary, process paper, argument
- Materials: poster board or website builder, slides
- Assessment: Project rubric.

### Spanish IV: Proyecto final: presentación
- Objective: Present a culminating project and reflect on growth
- Vocabulary: reflexionar, el progreso, la meta
- Materials: finished project
- Assessment: Project and reflection rubric.

### Theatre & Performing Arts: Final production
- Objective: Perform a one-act production for a live audience
- Vocabulary: dress rehearsal, house manager, performance, strike
- Materials: full production elements, programs
- Assessment: Performance rubric.

### Lifetime Fitness: Final fitness assessment
- Objective: Complete final fitness assessment
- Vocabulary: post-test, growth
- Materials: stopwatch, measuring tape, sit-and-reach box
- Assessment: Final fitness report.

### Introduction to Engineering Design (CTE): Capstone: technical report and portfolio
- Objective: Write a technical report
- Objective: Build a digital engineering portfolio
- Vocabulary: technical report, executive summary, appendix, portfolio
- Materials: word processor, free website builder
- Assessment: Technical report and portfolio.
