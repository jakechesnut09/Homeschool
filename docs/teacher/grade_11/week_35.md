**Watch for:**
- Choosing only favorite pieces. Include work that shows range and growth.
- Writing a vague reflection ('I improved a lot'). Point to specific evidence from pieces.

Today's task from the plan: Choose a theme (freedom, identity, the frontier, dissent) and map it across six texts from different periods. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** Give a sample theme map for 'dissent.'
  **A:** Paine and Henry (political revolution), Thoreau's 'Civil Disobedience,' Douglass' Fourth of July speech, Miller's The Crucible (Proctor's refusal), and King's 'Letter from Birmingham Jail.'

### Day 2 (Tuesday): Portfolio selection
*Student:* Select four best pieces and revise one substantially.

*How to teach:* The student selects four best pieces and revises one substantially. Today's task from the plan: Select four best pieces and revise one substantially. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** What counts as substantial revision?
  **A:** Changes to thesis, structure, or evidence—not just corrections.

### Day 3 (Wednesday): Reflection
*Student:* Write a 600-word reflective letter on growth as reader and writer.

*How to teach:* The student writes a 600-word reflective letter on growth. Today's task from the plan: Write a 600-word reflective letter on growth as reader and writer. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** What should the letter include?
  **A:** Specific evidence of growth from two or more pieces, a challenge overcome, and goals for next year.

### Day 4 (Thursday): Publish
*Student:* Build a digital portfolio site with pieces, reflection, and a reading list.

*How to teach:* The student builds the portfolio site. Today's task from the plan: Build a digital portfolio site with pieces, reflection, and a reading list. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** What belongs in the portfolio?
  **A:** Four pieces (one revised), the reflection, the theme map, and a reading list.

### Day 5 (Friday): Present
*Student:* Present portfolio and thematic map to family in a 10-minute talk.

*How to teach:* The student presents a 10-minute talk. Today's task from the plan: Present portfolio and thematic map to family in a 10-minute talk. Grade it the same day with the key below and have the student correct every missed item with a one-line note on what went wrong.

**Answer key:** Portfolio rubric (4-point): selection shows range; revision is substantial; reflection cites evidence; site is organized and complete. Presentation: clear, 10 minutes, answers questions.

## Algebra II: Modeling capstone

**Prepare:** Help the student find a public data set: California Department of Finance population, NOAA monthly temperatures, etc. Desmos.

**Watch for:**
- Choosing the model with the best R² even if it makes absurd predictions. A model must also make sense in context (e.g., population can't go negative).
- Extrapolating far outside the data range. Discuss how uncertainty grows beyond the data.

### Day 1 (Monday): Choose data
*Student:* Choose a real data set and graph it.

*How to teach:* Student picks a data set of 15+ points and graphs it in Desmos, writing what pattern they see. Today's task from the plan: Choose a real data set and graph it. Before the student writes conclusions, check that the data table has units and repeated trials, and ask them to explain one result in their own words.

- **Q:** What pattern would you expect in 12 months of average temperatures?
  **A:** Periodic (sinusoidal), period 12 months.

### Day 2 (Tuesday): Model fitting
*Student:* Fit linear, quadratic, exponential, and sinusoidal models; compare residuals.

*How to teach:* Fit linear, quadratic, exponential, and sinusoidal regressions; plot residuals for each. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** What does a good residual plot look like?
  **A:** Residuals scattered randomly around 0 with no curve or pattern.

### Day 3 (Wednesday): Justification
*Student:* Write a justification for the best model, including limitations.

*How to teach:* Student writes a one-page justification: chosen model, evidence (residuals, context), and limitations. Today's task from the plan: Write a justification for the best model, including limitations. Use the questions below as a quick oral check; if an answer is shaky, reteach with one more example before moving on.

- **Q:** Why might an exponential model fail for long-term population predictions?
  **A:** Resources limit growth; real populations level off (logistic), so exponential overpredicts.

### Day 4 (Thursday): Presentation
*Student:* Prepare a 5-minute presentation of the model and predictions.

*How to teach:* Student prepares a 5-minute presentation with a graph, model equation, predictions, and limits. Rehearse once. Today's task from the plan: Prepare a 5-minute presentation of the model and predictions. Grade it the same day with the key below and have the student correct every missed item with a one-line note on what went wrong.

- **Q:** What should every prediction slide include?
  **A:** The input value, predicted output with units, and a statement of confidence/limitations.

### Day 5 (Friday): Present
*Student:* Present the capstone and answer questions.

*How to teach:* Student presents; you ask two questions about model choice and limits. Today's task from the plan: Present the capstone and answer questions. Grade it the same day with the key below and have the student correct every missed item with a one-line note on what went wrong.

- **Q:** Your model predicts a value 30 years ahead. How confident should we be?
  **A:** Not very: extrapolation far beyond the data assumes the pattern continues, which is uncertain.

**Assessment:** Capstone presentation rubric.

**Answer key:** Capstone rubric (4 levels per row): Data (relevant, cited source, 15+ points); Models (at least 3 fitted, equations stated); Justification (residuals and context used to choose, limitations stated); Predictions (reasonable, within or near data range, with units); Presentation (clear, 5 minutes, answers questions). Proficient (3) = all rows present and correct with minor gaps.

## Physics of the Universe: Engineering capstone: build a generator or wind turbine

**Prepare:** Small 3–6 V DC hobby motor (to use as a generator), cardboard or cut plastic-bottle blades, a hub (bottle cap or cork), hot glue (adult), an LED (or multimeter), a box fan, a ruler and protractor. Safety: keep fingers clear of spinning blades and fan.

**Watch for:**
- Thinking more blades always means more power. Extra blades add drag and mass; real turbines usually use three as a balance of efficiency, cost, and stability.
- Changing several things between tests and recording nothing. Keep a data table and change one variable (blade angle OR number) at a time.

### Day 1 (Monday): Define & research
*Student:* Define criteria (light an LED, maximize voltage) and constraints; read how turbines convert wind energy via induction.

*How to teach:* Set criteria (light the LED; maximize voltage at the highest fan speed) and constraints (materials list, 30 cm maximum blade length). Read how turbines convert wind energy using induction.

- **Q:** How does a wind turbine produce electricity?
  **A:** Wind pushes on angled blades, turning a shaft connected to a generator; coils rotating in a magnetic field induce current (electromagnetic induction).

### Day 2 (Tuesday): Simulate & design
*Student:* Use a PhET or online wind simulation to explore blade number and angle, then sketch three designs and pick one with a decision matrix.

*How to teach:* Use a wind-turbine simulation (or online interactive) to explore blade number and pitch; sketch three designs and choose one with a decision matrix. Today's task from the plan: Use a PhET or online wind simulation to explore blade number and angle, then sketch three designs and pick one with a decision matrix. Before the student writes conclusions, check that the data table has units and repeated trials, and ask them to explain one result in their own words.

- **Q:** Why does blade angle (pitch) matter?
  **A:** The angle determines how much of the wind's push becomes rotation; too flat catches little force, too steep creates drag and stalls.

### Day 3 (Wednesday): Build
*Student:* Build a turbine with bottle or cardboard blades attached to a small DC motor and mount it in front of a box fan.

*How to teach:* Build the turbine: attach blades evenly to the hub, press the hub onto the motor shaft, wire the motor leads to the LED (try both polarities, since LEDs conduct one way).

- **Q:** Why can a DC motor act as a generator?
  **A:** Turning its shaft spins coils inside the motor's magnetic field, which induces a voltage across its leads.

### Day 4 (Thursday): Test & iterate
*Student:* Test at three fan speeds and two blade angles, recording LED brightness or voltage; revise the design once based on data.

*How to teach:* Test at three fan speeds and two blade angles, recording voltage or LED brightness (3 trials each). Revise once based on the data and retest. Grade it the same day with the key below and have the student correct every missed item with a one-line note on what went wrong.

- **Q:** What should the data table contain?
  **A:** Fan speed setting, blade angle, number of blades, trial number, and voltage (or brightness rating), plus averages.

### Day 5 (Friday): Present
*Student:* Present the final device, data table, and efficiency discussion in a 5-minute engineering briefing.

*How to teach:* The student gives a 5-minute engineering briefing: final design, data table, the revision and why, and an efficiency discussion. Today's task from the plan: Present the final device, data table, and efficiency discussion in a 5-minute engineering briefing. Grade it the same day with the key below and have the student correct every missed item with a one-line note on what went wrong.

- **Q:** Why is a small homemade turbine's efficiency low?
  **A:** Energy is lost to air passing between blades, friction in the motor, electrical resistance (heat), and turbulence; real turbines can capture at most about 59% of wind energy (Betz limit).

**Assessment:** Capstone design rubric.

**Answer key:** Capstone design rubric (4-point per row): Problem definition (criteria and constraints stated); Design process (three sketches and decision matrix); Data (multiple conditions with repeated trials, organized table/graph); Iteration (one change justified by data, with retest results); Explanation (correct physics of induction and energy conversion, honest efficiency discussion). Proficient = LED lights or measurable voltage, data supports the chosen revision, explanation uses induction correctly.

## U.S. History & Geography: Continuity and Change in the Twentieth Century: History research project: build and present

**Prepare:** Poster board or a website builder (NHDWebCentral) or video tools; slides; the NHD rule book for word limits (exhibits 500 student-composed words; papers 1,500–2,500 words; process paper up to 500 words); a project rubric.

**Watch for:**
- Students build first, argue later. Outline thesis, context, evidence and significance before building.
- Students fill projects with quotes. Balance primary-source evidence with the student's own analysis.

*How to teach:* Build the exhibit, website, documentary or paper.

### Day 3 (Wednesday): Process paper

*How to teach:* Write the 500-word process paper.

## Theatre & Performing Arts: Final production

**Prepare:** All production elements, printed programs, a house manager (family member) for seating, video camera. Plan strike crew assignments.

**Watch for:**
- Skipping notes after the preview audience. Audience reactions reveal timing (laughs, holds).
- Breaking character when the audience laughs. Hold for laughs, then continue.
- Leaving strike unplanned. Assign who returns what.

### Day 1 (Monday): Dress rehearsal 1
*Student:* Run the full play in costume with timing notes.

*How to teach:* Full dress rehearsal with timing; give notes.

- **Q:** What is 'holding for a laugh'?
  **A:** Pausing in character until the laugh peaks and begins to fade before the next line.

### Day 2 (Tuesday): Dress rehearsal 2
*Student:* Final dress with an invited preview audience.

*How to teach:* Final dress with a preview audience; adjust.

- **Q:** Why invite a preview audience?
  **A:** To practice with real reactions and adjust timing and volume.

### Day 3 (Wednesday): Performance 1
*Student:* Perform the one-act for an audience.

*How to teach:* Perform the one-act.

- **Q:** What does the house manager do?
  **A:** Manages the audience: seating, tickets/programs, start time, and safety in the house.

### Day 4 (Thursday): Performance 2
*Student:* Perform a second time and record it.

*How to teach:* Second performance; record it.

- **Q:** Why is a second performance often stronger?
  **A:** Actors are more relaxed, notes from the first performance are applied, and timing settles.

### Day 5 (Friday): Strike
*Student:* Strike the set and return materials.

*How to teach:* Strike: dismantle set, return materials, clean space.

- **Q:** What is strike?
  **A:** Taking down the set and clearing the performance space after the final performance.

**Assessment:** Performance rubric.

**Answer key:** Performance rubric. 4 – Polished production: memorized, clear objectives, consistent blocking, smooth tech, strong pacing and audience connection, professional front-of-house and strike. 3 (proficient) – Memorized, audible, motivated staging, tech mostly smooth. 2 – Noticeable gaps. 1 – Incomplete.

## Lifetime Fitness: Final fitness assessment

**Prepare:** Gather stopwatch, measuring tape, sit-and-reach box, baseline and midyear data. Use the same routes and protocols. Schedule tests after a rest day.

**Watch for:**
- Expecting improvement in every test. Maintenance in some components is also success.
- Comparing to classmates. Compare to your own past results and HFZ.
- Ignoring test conditions. Note weather, sleep, and illness.

### Day 1 (Monday): Aerobic test
*Student:* Complete the 1-mile run/walk and resting heart rate.

*How to teach:* Mile run/walk and resting HR, same protocol as before.

- **Q:** Mile: 10:40 baseline, 9:52 midyear, 9:20 final. Total improvement?
  **A:** 80 seconds (1:20) faster than baseline.

### Day 2 (Tuesday): Muscular test
*Student:* Complete push-up, curl-up, and plank tests.

*How to teach:* Push-ups, curl-ups (cadence), plank hold.

- **Q:** Why is the plank a measure of muscular endurance rather than strength?
  **A:** It measures how long muscles can sustain a contraction, not maximal force.

### Day 3 (Wednesday): Flexibility test
*Student:* Complete sit-and-reach and shoulder stretch.

*How to teach:* Sit-and-reach (both sides) and shoulder stretch.

- **Q:** Sit-and-reach went from 8 to 11 inches. Percent change?
  **A:** (11 − 8) ÷ 8 = 37.5% increase.

### Day 4 (Thursday): Analysis
*Student:* Compare results across baseline, midyear, and final.

*How to teach:* Build a table and line graph showing baseline, midyear, final for each measure.

- **Q:** Which graph type best shows change across three time points?
  **A:** A line graph (or clustered bar graph) with time on the x-axis.

### Day 5 (Friday): Check
*Student:* Write a fitness report.

*How to teach:* Student writes the final fitness report.

- **Q:** What should explain any decline in a test?
  **A:** Factors like reduced training emphasis, test conditions, illness, sleep, or growth; and a plan to address it.

**Assessment:** Final fitness report.

**Answer key:** Final fitness report rubric. 4 – All tests done with correct protocols; data table and graphs across three points; HFZ comparison; correct calculations; analysis linking results to training choices; next goals. 3 (proficient) – Complete data, graph, HFZ comparison, explanation. 2 – Partial analysis. 1 – Incomplete.

## Introduction to Engineering Design (CTE): Capstone: technical report and portfolio

**Prepare:** Have a word processor and a free website builder (Google Sites works well). Collect renderings, drawings, build photos and test graphs into one folder.

**Watch for:**
- Writing the executive summary first. Write it last, as a short summary of the whole report.
- Using vague words ('pretty strong'). Use technical terms and data ('held 3.2 kg, SD 0.2 kg').
- Missing citations for research, images or patents.

### Day 1 (Monday): Report outline
*Student:* Outline the report: executive summary, problem, research, concept selection, design, testing, conclusions, and citations.

*How to teach:* Outline the report sections.

- **Q:** What belongs in an executive summary?
  **A:** A brief overview of the problem, solution, key test results and conclusions — readable on its own by a busy reader.

### Day 2 (Tuesday): Report draft
*Student:* Write the full technical report draft (2,000+ words) with figures and data tables.

*How to teach:* Write the full draft with figures and data tables.

- **Q:** How should figures be labeled?
  **A:** Numbered with a caption (e.g. 'Figure 3. Load test results over five trials'), and referred to in the text.

### Day 3 (Wednesday): Portfolio
*Student:* Build a digital portfolio page with renderings, drawings, build photos, and test graphs.

*How to teach:* Build the digital portfolio page.

- **Q:** What should a portfolio show a college or employer?
  **A:** The problem, process, visuals of the design and build, test evidence, and what the student learned.

### Day 4 (Thursday): Revision
*Student:* Revise the report for clarity and correct technical terminology; check all sources are cited.

*How to teach:* Revise for clarity and terminology; check every source is cited.

- **Q:** Replace 'the stand was pretty strong' with technical language.
  **A:** 'The stand supported a 300 g load with no measurable deflection across five trials.'

### Day 5 (Friday): Submit
*Student:* Submit the final report and publish the portfolio.

*How to teach:* Submit the report and publish the portfolio.

- **Q:** Why put test data in an appendix?
  **A:** Full raw data supports the report's claims while keeping the main text readable.

**Assessment:** Technical report and portfolio.

**Answer key:** Technical report and portfolio rubric: 4 = report of 2,000+ words with executive summary, problem, research, concept selection, design (drawings/renderings), build, testing (tables and graphs with data), conclusions/recommendations and citations; correct technical vocabulary; figures numbered and captioned; portfolio page publicly viewable with renderings, drawings, build photos, test graphs and a short project summary; 3 = minor gaps; 2 = missing sections or data; 1 = incomplete.
